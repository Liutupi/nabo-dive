# NABO《深潜 DIVE》— 第 1 轮造型设计

当前停在选型阶段。请选 A / B / C，或指定混合与修改；选型确认后才进入第 2 轮。本轮没有制作骨骼、动作帧、动画、游戏界面或固件集成。

| --- | --- | --- | --- |

| B `option_b.png` 珊瑚救援 | 改为珊瑚橙救援夹克与裤装，保留白肩带和腰带；深海反差强，省略听诊器。 | 腰侧白色救援织带 | 20 |

三套均保留男性 Q 版头脸、蓬松棕发、细圆眼镜、自然戴合的白棒球帽、蓝色 NABO 与心电图、白鞋；不带宠物。参考只用于身份与形体识别，全部 SVG 为本任务原创绘制，没有复制参考图片像素。画面采用平涂、两阶硬边赛璐珞阴影与粗内描边，外围为浅色硬描边，无软 3D、渐变光照或光晕。

每张 1600×1200 设计板都含往左下约 50° 的全身潜姿（3/4 转脸）、正面全身、配色色块，以及在 `#0B2A4A` 和 `#04070D` 背景上的 56 px 实际高度预览与最近邻 4 倍图。帽标文字在大图可读；56 px 以白帽、蓝色标记、棕发与圆镜共同识别，不依赖微小文字阅读。

## 源文件与单独预览

- `sources/option_{a,b,c}_{dive,front}.svg`：六张可编辑、具名分组的原创矢量。头、表情、帽、头发、躯干、前后臂、腿、鞋、飘动部件分别具名，供选型后提取与进一步拆分。尚未创建 rig 或支点合同。
- `sources/option_{a,b,c}_{dive,front}.png`：对应 256×256 RGBA 静态设计样图，胸口中心保持 `(128,128)`。
- `previews/option_*_56.png`：紧裁切透明角色，非透明包围框严格为 **50×56 px**。
- `previews/option_*_{deep,black}_actual.png`：180×104 实际尺寸背景展示；同前缀 `_4x.png` 是整幅预览的严格最近邻 4 倍图。
- `sources/palette.json`：设计色板及 RGB565 对照，仅为本轮角色与设计板配色；不是第 4 轮海洋分层色表。
- `qa/checks.json`：尺寸、非透明包围框、实际 RGB 色数、16 级 alpha 与设计板 SHA256。

已目视检查三套大图及两种背景的实际 56 px / 4 倍图。检查后增强 A 白褂白块，修正 C 领带尾朝脚侧随流，强化潜姿头脸透视，并清除文字缺字。三套轮廓都与深色背景分离，帽子与头发贴合、手脚完整、腿间负形保留；未代用户选择最终方案。

## 静态复现

依赖：Python 3、CairoSVG（需本机 Cairo）、Pillow、NumPy。当前环境已验证可运行。

```sh
python3 game-art/dive/design/build_designs.py
```

脚本只重建本目录的静态方案、源文件和 QA 数据，不生成动画。若后续另存不同版本，请先复制到新的版本目录，避免重建覆盖人工修改。原有 `ART_BRIEF.md`、`CODEX_PROMPTS.md` 与上传版仅差末尾换行，已保留原件。
